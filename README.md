🍬 Sweet Shop Management System

🚀 Production-Ready Full-Stack E-Commerce Platform

A modern, scalable Sweet Shop Management System built with industry-grade technologies to simulate a real-world e-commerce application.
This project demonstrates secure authentication, role-based access control, and a modular architecture suitable for production deployment.

---

🌐 Live Demo

🔗 https://sweet-shop-green-two.vercel.app

---

📌 Overview

This platform enables customers to explore and interact with a digital sweet shop while providing administrators with tools to manage products and operations efficiently.

👥 User Roles

- Customer – Browse sweets, authenticate securely
- Admin – Manage application through a protected dashboard

---

🏗️ Architecture

- Modular and scalable architecture
- API-driven backend design
- Separation of concerns (UI, business logic, data layer)
- Role-based access control (RBAC)

---

🛠️ Tech Stack

🎨 Frontend

- Next.js (App Router)
- React
- TypeScript
- Tailwind CSS

⚙️ Backend / Services

- RESTful API architecture

- Middleware-based route protection

🗄️ Database (Extensible)

- Prisma ORM (recommended)
- PostgreSQL / MongoDB (production-ready upgrade)
